# Demo assets

Add only synthetic designs or assets the team owns and has agreed to publish. This repository is public.

The local demo's original sample posters are drawn in the browser by `src/lib/samples.js`, then encrypted before upload. Project-card covers are decorative CSS shapes, not previews of private drafts.

Use a small image for the first demo. Runtime uploads and encrypted payloads belong in the configured storage, not in Git. Never commit real unreleased client work or personal data.
